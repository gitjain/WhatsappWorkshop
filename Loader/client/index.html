How This Demo Works

Your Browser ──→ NGINX (port 80) ──→ Server 1 (green) │ ├──→ Server 2 (blue) │ └──→ Server 3 (orange)

What you're seeing: All your requests go to NGINX on port 80. NGINX decides which of the 3 backend servers handles each request. The colors show which server responded.

Try these experiments:
1. Click "Send 1 Request" multiple times - watch the distribution
2. Click "Burst 10 Requests" - see how traffic spreads
3. Click "Slow Request" - these take longer, affecting load balancing
